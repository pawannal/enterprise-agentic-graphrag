# ADR-002: Migrate Agent Orchestration to LangGraph

Decision ID: ADR-002

Date: July 10, 2026

Project Phoenix originally evaluated LangChain for agent orchestration.

The AI Platform Team decided to use LangGraph for stateful agent workflows.

LangGraph provides better support for multi-step agent workflows and controlled tool execution.

Project Orion also adopted LangGraph for its agent architecture.

This decision replaced the earlier LangChain-based orchestration approach.

The decision was approved by the AI Platform Team.
