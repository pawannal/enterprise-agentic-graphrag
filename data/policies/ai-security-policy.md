# AI Security Policy

NexaAI AI applications must protect enterprise and customer information.

AI agents must not access sensitive data unless the user and agent have the required permissions.

Production AI systems must use approved models, tools, and data sources.

AI applications must implement authentication and authorization.

AI agents must not bypass security controls when selecting or invoking tools.

Project Phoenix, Project Orion, and Project Sentinel must comply with this policy.

The Security Engineering Team owns the AI Security Policy.
