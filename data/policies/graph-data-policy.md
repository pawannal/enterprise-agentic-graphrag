# Graph Data Policy

Knowledge graphs containing enterprise information must follow NexaAI data governance requirements.

Graph entities and relationships must have traceable source documents.

Sensitive customer information must not be stored in graph properties unless explicitly approved.

Knowledge graph updates must preserve data lineage.

GraphRAG applications must provide source references when enterprise information is used to generate an answer.

Project Phoenix must follow this policy because its GraphRAG system stores enterprise entities and relationships in Neo4j.
