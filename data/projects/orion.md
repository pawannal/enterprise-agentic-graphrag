# Project Orion

Project Orion is an AI agent platform developed by NexaAI.

The project receives architecture guidance from the AI Platform Team.

Orion uses Python, LangGraph, MCP, OpenAI, and AWS.

The platform provides AI agents with access to enterprise tools through the Model Context Protocol.

Project Orion is currently in development.

The architecture team is evaluating Neo4j for future knowledge graph capabilities.
