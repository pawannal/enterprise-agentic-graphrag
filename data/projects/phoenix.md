# Project Phoenix

Project Phoenix is an enterprise GraphRAG platform developed by NexaAI.

The project is owned by the AI Platform Team and serves Acme Bank.

Phoenix uses Neo4j as its graph database, OpenAI for large language model capabilities, LangGraph for agent orchestration, Python for application development, and MCP for tool integration.

The platform combines vector retrieval with knowledge graph retrieval to answer questions about enterprise projects, technologies, policies, and incidents.

Pawan Vannal and Priya Sharma work on Project Phoenix.

Project Phoenix started development in June 2026 and is currently in development.
