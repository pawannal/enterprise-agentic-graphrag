# Neo4j

Neo4j is a graph database used to store entities and relationships.

Project Phoenix uses Neo4j as its knowledge graph database.

Project Atlas is evaluating Neo4j for graph-based data exploration.

Neo4j supports Cypher for querying connected data.

The Phoenix GraphRAG platform uses Neo4j for knowledge graph retrieval and relationship-based reasoning.

Neo4j is also referred to as the Neo4j Graph Database or Neo4j DB in some internal documents.
